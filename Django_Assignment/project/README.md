# Django Login System with CRUD Operations

## Project Overview
This project is a Django-based Login System developed as part of the **CA2021 Git & Django Assignment**.  
It demonstrates end-to-end Django development including project setup, app creation, models, views, URL routing, templates, admin panel usage, Django shell operations, and CRUD APIs tested using Postman.

---

## Features Implemented

### Task 1 – Django Setup
- Created virtual environment
- Installed Django
- Created Django project
- Ran the Django server

### Task 2 – App Creation
- Created `accounts` app
- Added app to settings
- Configured URLs

### Task 3 – Login System
- Created `UserDetails` model with:
  - Username
  - Email
  - Password
- Implemented signup page
- Implemented login page
- Created basic HTML templates for signup, login and success page

### Task 4 – Admin Panel and Django Shell
- Created superuser
- Accessed Django admin panel
- Performed create, read, update and delete operations using Django shell

### Task 5 – CRUD APIs using Postman
- Created API to get all users
- Created API to get user by email
- Created API to update user password
- Created API to delete user by email
- Tested all APIs using Postman
